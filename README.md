<details>
<summary>Metrics setup</summary>

Add a classic GitHub personal access token as the repository Actions secret `METRICS_TOKEN`, then run **Actions → Update profile → Run workflow** on `main`. For public-only metrics, use `read:user` without the broad `repo` scope. The supplied guide's additional `repo` scope grants access to private repositories and can expose their metrics on this public profile; add it only if you explicitly intend that.

The workflow's repository-scoped token publishes the image; the personal token is used only by the metrics action to read data. Without this secret, metrics generation is skipped and snake/recent-activity updates still run. No token belongs in this README or a commit.

</details>
