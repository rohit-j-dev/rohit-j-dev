<summary>Behind the dashboard</summary>

Refreshed daily at 03:00 UTC (08:30 IST) using public GitHub data only. Sparse activity and missing language data are shown honestly, not replaced with sample numbers or skills.

[Profilescape](https://github.com/chethandvg/profilescape) renders the Aurora cards to the dedicated `profilescape-output` branch; [snk](https://github.com/Platane/snk) generates the contribution snake in `assets/` on `main`. The README layout is hand-maintained so the cards stay tightly stacked. Images refresh without rewriting this layout.

Both actions are pinned to immutable commits. Only the repository-scoped workflow token is used, with contents write permission for publishing; no personal access token or private repository access is configured. The card output branch is replaced on refresh, while `main` retains normal commit history.
